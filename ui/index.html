Display Scale Warning ×
Your Windows display scale is -, not 100%. Every click/search position this macro uses was captured at 100% scale, so anything else is a common cause of clicks landing slightly wrong or buttons not being found.
Fix: Windows Settings > System > Display > Scale — set it to 100%, then restart your computer (not just the macro) — Windows and Roblox don't always fully pick up a scale change until everything's been relaunched fresh.
If clicks/detection are still off after that, also try: set the game's own UI scale to 1x (in-game Settings), turn off HDR (Windows Settings > Display), and if your monitor runs a high refresh rate, try dropping it under 100Hz — some setups render color slightly differently at very high refresh rates, which can throw off the macro's image matching.

Help & Troubleshooting FAQ
×

Yes, the macro is safe and open-source.

PyInstaller executables often trigger false positives in basic antivirus scans. The whole thing is open source and can be run straight from source.

1. Open the Task tab in the top menu.

2. Add a task and set Mode to Raid.

3. In the Stage dropdown, choose Stage 3 (Act 3) or Stage 2 (Act 2).

4. Pick Solo or Matchmaking under Play Mode.

A running background process might lock the executable file from being overwritten.

Fix: Close all macro processes in Task Manager, or unpack a fresh copy of the macro into a new folder.

This happens when Windows Display Scaling is above 100% or GPU settings interfere with screen captures.

Fix:

1. Open Settings > Capture in the macro.

2. Turn on Hardware Capture Fix (Windows.Graphics.Capture) and restart the macro.

3. Set Roblox to Windowed Mode instead of Fullscreen.

Inverted camera controls in Roblox cause this behavior.

Fix: Open Roblox settings (Esc > Settings), turn off Invert Camera Y-Axis, and set Camera Mode to Default (Classic).

Defense nodes in Expeditions clear placed phantom units by design.

For standard stages, open Macro Manager, select your Place Unit block, and enable Keep Placing to retry placement automatically until confirmed.
