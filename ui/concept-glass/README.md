# Concept "Glass" v2 - редизайн интерфейса AE Macro

Интерактивный статический концепт в монохромном стеклянном стиле:
графит + белое стекло (тема Onyx) или светлый вариант (Pearl). Топ-навигация,
стеклянные карточки, белые pill-кнопки, цвет только для исходов матча.

Основной `ui/index.html` **не тронут** - это отдельная папка для просмотра.

## Как посмотреть

Открыть `index.html` двойным кликом в браузере (Chrome / Edge). Без сети и установки.

Deep-link для быстрого доступа: `index.html#screen=settings&tab=appearance&theme=pearl`.

## Экраны

| Экран | Что внутри |
|---|---|
| Home | Док-окно Roblox с точной пропорцией 1152 × 756 и хром-полосой, Start/Pause/Stop, режим Auto, статистика сессии, живой журнал, история забегов |
| Tasks | Очередь задач, опции очереди, пресеты |
| Scenarios | Редактор сценария: фазы Pre Start / Battle, ветвящийся Detect, палитра блоков |
| Recordings | Кнопка записи с таймером, библиотека, стартовая задержка |
| Settings | Отдельные вкладки: Game Window, Hotkeys, Appearance, Discord, Updates, Debug |

Настройки открываются вкладками, а не одной длинной страницей.

## Что интерактивно

Навигация, вкладки настроек, тумблеры, смена темы (Onyx / Pearl) и плотности,
привязка хоткеев (клик по клавише, затем нажать новую), таймер записи,
Start запускает живой журнал, счётчики и победы в истории.

## Что замокано

Все данные выдуманы, кнопки без поведения показывают тост "demo".
К Python обращений нет.

## Своя подложка

По умолчанию фон - градиентная атмосфера. Положи рядом `bg.jpg` - подхватится.

## Соответствие реальному макросу

Экраны повторяют текущие: Home = Панель, Tasks = Задачи, Scenarios = Сценарии,
Recordings = Запись, Settings = Настройки. Названия блоков, задач и настроек
взяты из реальных (`Inf Summer`, Repeat Game on wave limit, OCR-проверка удочки,
стартовая задержка записи и т.д.). При переносе в приложение тексты экранов
остаются английскими, русский придёт словарём `ui/i18n.js`.
