Help & Troubleshooting FAQ

Yes, 100% safe and open source. The macro is compiled from open-source Python code using PyInstaller. Antivirus engines frequently flag PyInstaller-bundled executables as generic heuristic threats (such as Trojan.Agent or Generic.Malware) simply because they unpack an interpreter to memory, and because the macro hooks the keyboard to handle emergency stop keys (F2).

You can inspect all source code directly in the GitHub repository or build it yourself. To prevent Defender from deleting the file, add the macro folder to Windows Defender Exclusions.

Start Roblox and join the game first, then press F4 or click Attach window on the Home screen. The macro finds the Roblox process window and embeds it via Windows SetParent at the fixed resolution of 1152 × 756.

Make sure Roblox and the macro are running under the same user privileges (do not run Roblox as Administrator if the macro was launched as normal user).

Windows intentionally discards synthetic mouse clicks if the game window is minimized to the taskbar. Keep the macro window visible on your screen.

You can navigate between tabs in the macro without minimizing. If clicks stop working, press F4 twice to re-dock and refresh window input focus.

The wave counter uses native Windows Media OCR (en-US). If missing, click the Bell notification in the top titlebar and hit Install, or install it via Windows Settings → Time & Language → Language → English (United States) → Add OCR.

Even without OCR, the macro has a built-in time-based fallback timer that automatically safeguards Infinite runs and restarts on schedule without freezing.

Roblox camera zoom and pitch must remain in the standard default third-person view. If zoomed in to first-person mode, image recognition for portals and lobby NPCs will fail.

Ensure graphics quality is set to low (level 1-3) in Roblox Settings for stable framerates and consistent template matching.

Scenarios are JSON files stored in the Templates folder. Action recordings are stored in Recordings.

You can import templates from friends or paste CREAM share codes directly via Tasks → Import JSON. All recordings replay tick-for-tick without needing template configuration.

Open Settings → Discord, paste your Discord Channel Webhook URL, and enable match notifications. The macro generates OpenCV match outcome status cards with wave count, duration, and victory/defeat badges, and includes automatic retries on Discord rate limits.

If you use Windows display scaling (e.g. 125% or 150%), image recognition might miss templates if Windows blurs the game window.

Right-click RobloxPlayerBeta.exe → Properties → Compatibility → Change high DPI settings → Override high DPI scaling behavior: set to Application.
